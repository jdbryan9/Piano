# Piano Keyboard

A simple browser-based piano keyboard that plays notes when you click, tap, or press matching computer keys.

## How to Use

Open `index.html` in a modern web browser.

No install step or development server is required. The piano uses the browser's built-in Web Audio API.

## Keyboard Controls

White keys:

| Key | Note |
| --- | --- |
| A | C4 |
| S | D4 |
| D | E4 |
| F | F4 |
| G | G4 |
| H | A4 |
| J | B4 |
| K | C5 |

Black keys:

| Key | Note |
| --- | --- |
| W | C#4 |
| E | D#4 |
| T | F#4 |
| Y | G#4 |
| U | A#4 |

## Files

- `index.html` builds the page and keyboard buttons.
- `styles.css` styles the piano and responsive layout.
- `script.js` handles keyboard input and sound playback.
